# Third-party data

`geo_all_channels.csv` is an unmodified copy of the simulated geo file from Google's Meridian project:

https://github.com/google/meridian/blob/main/meridian/data/simulated_data/csv/geo_all_channels.csv

Google distributes that file under the Apache License, Version 2.0. A copy of that license is `LICENSE` in this directory. The MIT license at the repository root does not cover this file.

The example scripts download the same file from that URL when this copy is absent.
